Q1：VLM 三种架构范式？

展开答案

核心原理

浅层对齐（LLaVA）——冻 ViT 和 LLM，只训中间投影层。快便宜，深层理解受限。深度预训练（Qwen2-VL）——从头图文联合训练，理解力最强但训练成本极高。Perceiver-Reasoner 分离（2025 新趋势）——轻量 VLM 看图生成描述，强文本 LLM 做推理。各干专长，效果超 GPT-4o。The Boy 用范式 3 思路——Qwen2-VL 入库时生成描述，之后全走文本检索。

面试话术

“LLaVA=浅对齐（只训中间层），Qwen-VL=深预训（图文一起训），分离式=看图归看图推理归推理。Agent 开发不深究原理，记住范式 3 性价比最高就行。”

Q2：为什么”轻量 VLM+强 LLM” > GPT-4o？

展开答案

核心原理

任务分离——GPT-4o 一个模型同时做视觉识别、语义理解、知识推理、回复生成，四个任务抢算力。分离后小 VLM 专注看图说话，强 LLM 专注推理——各司其职。不需要 VLM 很强、不需要 LLM 有视觉能力。The Boy 就用这个思路。

面试话术

“GPT-4o 一脑四用——看图+理解+推理+生成抢算力。分离后各干专长——VLM 看图→文字，LLM 看文字→推理。效果反而好。”

易混淆点

  • ❌ “和投机解码一样” → ✅ 投机解码是同任务提速，这是分任务提效果，完全两码事

Q3：语音 Agent 为什么生产选级联而不是端到端？

展开答案

核心原理

级联是 ASR→LLM→TTS 三段流水线，文字做中转，每段独立优化——可控性高。端到端是一个模型语音直进直出，延迟低 300ms 但黑盒不可控。生产选级联因为稳定性和可维护性比几百毫秒延迟更重要——和 MCP 模块化一个道理。

面试话术

“级联=三段独立，可控可换。端到端=一模型全包，快但黑盒。生产选级联——稳定>300ms。ASR 不准换 ASR，TTS 不好换 TTS，端到端出问题不知哪段。”

Q4：Whisper 模型怎么选型？

展开答案

核心原理

生产默认 base+faster-whisper——8.2% WER 够用，0.8× 实时因子不卡。需要高质量用 large-v3，5.1% WER 但更大更慢。IoT/离线用 tiny+whisper.cpp。关键是 RTF < 1.0 不能卡——识别 1 秒音频的处理时间必须 < 1 秒。

面试话术

“base+faster-whisper 生产默认，WER 8.2% 够、RTF 0.8× 不卡。高要求上 large-v3（5.1%），IoT 用 tiny。核心指标 RTF<1，否则处理速度追不上输入。”
