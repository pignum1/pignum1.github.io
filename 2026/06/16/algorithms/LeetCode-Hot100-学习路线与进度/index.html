LeetCode Hot 100 — 学习路线与进度

与 The Boy Assistant 多 Agent 项目并行推进。Python 讲思路 + Java 版本对照，每天 2-3 题，按题型分组，每完成一组总结通用模板。

一、学习方法

每道题固定五段式结构：

  1. 题目速览 — 一句话题意 + 难度 + 标签
  2. 思路推演 — 从暴力解到最优解的思维过程（不是直接给答案）
  3. 复杂度 — 时间 / 空间
  4. 双语言代码 — Python（简洁，重思路）+ Java（严格，面试写）
  5. 面试要点 — 易错点、变种题、一句话模板

原则：先想再写。每道题先花 5 分钟想思路，想不出来再看解析。模板要背，但理解为什么用这个模板比背更重要。

三、核心模板预告

每个题型结束都会沉淀一个可复用模板，例如：

  • 哈希表：HashMap<key, value> 做「查找从 O(n) 降到 O(1)」
  • 滑动窗口：right 扩张 / left 收缩 的双指针固定套路
  • 回溯：for + 递归 + 撤销选择 的三件套
  • DP：状态定义 → 转移方程 → 初始化 → 遍历顺序
