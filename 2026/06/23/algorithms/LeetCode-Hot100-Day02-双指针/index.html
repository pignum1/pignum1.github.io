LeetCode Hot 100 Day 02 — 双指针应用（移动零 / 盛水容器 / 接雨水）

双指针有两个子模式：快慢指针（同向而行，一快一慢）和左右指针（相向而行，两端往中间靠）。今天三道题，各练一种，外加一道进阶。

本日题目：

# 题目 难度 双指针类型 核心思想
283 移动零 Easy 快慢（同向） slow=写入位，fast=扫描位，遇非零交换
11 盛最多水的容器 Medium 左右（相向） 动矮的那根——动高的永远不划算
42 接雨水 Hard 左右（相向） 维护左右 max，动 max 小的那边

一、#283 移动零 — 快慢指针

题目速览

给数组 nums，所有 0 移到末尾，保持非零元素相对顺序，原地操作。

[0,1,0,3,12] → [1,3,12,0,0]

思路：slow = 写入位，fast = 扫描位

fast 从左到右扫，遇到非零就和 slow 交换，slow++。slow 永远指向「下一个非零该放的位置」。

因为 fast ≥ slow，交换时 slow 位置要么是 0（被换走），要么等于自己（无影响），所以非零相对顺序天然保持。

复杂度

  • 时间 O(n)，一趟
  • 空间 O(1)

代码

Python：

Java：

走例 [0,1,0,3,12]

fast nums[fast] 动作 数组 slow
0 0 跳过 [0,1,0,3,12] 0
1 1 swap(0,1) [1,0,0,3,12] 1
2 0 跳过 [1,0,0,3,12] 1
3 3 swap(1,3) [1,3,0,0,12] 2
4 12 swap(2,4) [1,3,12,0,0] 3

面试要点

  • 为什么交换不用覆盖：覆盖会丢数据；交换把 0 顺手推到后面
  • 变种：#26 删除重复元素、#27 移除元素，都是同一套”快慢指针 + 交换/覆盖”
  • 为什么保持相对顺序：非零之间从不交换彼此，只和左边 0 交换

🔑 一句话模板：for fast: if 满足条件 → swap(slow, fast); slow++

二、#11 盛最多水的容器 — 左右双指针

题目速览

数组 height 每根是竖线高度。选两根线和 x 轴围成容器，求最多装多少水。

[1,8,6,2,5,4,8,3,7] → 49（下标 1 的 8 和下标 8 的 7，宽 7 × 矮高 7 = 49）

思路：左右指针 + 动矮的那根

从两端开始。面积 = 宽度 × 矮的那根高度。往中间收时宽度必定减小，要面积增大只能靠高度增加——所以永远移动较矮的那根，换掉它才可能找到更高的。

反证：如果动高的那根，新高度 ≤ 原来的矮高、宽度减小 → 面积一定 ≤ 原来。动高的不划算。

复杂度

  • 时间 O(n)
  • 空间 O(1)

最大 49。

三、#42 接雨水 — 左右双指针进阶

题目速览

数组 height 每根是柱子高度。下雨后柱子之间能接多少雨水？

[0,1,0,2,1,0,1,3,2,1,2,1] → 6

思路推演

按列算：每列能接的水 = max(0, min(左边最高墙, 右边最高墙) - 当前高度)。

暴力：每列各扫左右找最高，O(n²)。
前缀数组：一次左→右建 leftMax[i]，一次右→左建 rightMax[i]，O(n) 时间但 O(n) 空间。
双指针：用两个变量替代两个数组，O(n) 时间 + O(1) 空间。

双指针核心：一次遍历，同时维护左右 max

直觉：两个人从两端往里走，手牵手拦住水。矮的那边先走——因为它的水位已经由当前这侧的最高墙确定，不会因为更远的柱子再抬高。

复杂度

  • 时间 O(n)
  • 空间 O(1)

累计：0+0+0+1+0+1+0+0+1+2+1 = 6 ✅

四、#11 vs #42 对比

#11 盛水容器 #42 接雨水
求什么 两根线围出的最大面积 所有列上方水的总和
面积公式 宽 × 矮高 min(leftMax, rightMax) - cur
维护什么 只维护左右下标 维护 leftMax / rightMax 两个变量
双指针谁动 动矮的那根 动 max 更小的那边
核心直觉 “动高的一面不划算” “矮的那边水位已确定”

关键不在指针怎么走，而在于每一次决策为什么能排除一个方向——#11 是”动高不划算”，#42 是”矮侧水位已锚定”。能讲清楚这个”为什么”，才算真正吃透双指针。

六、本日回顾

题 核心技巧 双指针类型 易错点
#283 slow=写入位, fast=扫描位 快慢（同向） 用交换不用覆盖
#11 动矮的那根 左右（相向） 面积 = 宽 × 矮高
#42 维护 leftMax/rightMax，动 max 小的那边 左右（相向） 水量 = min(max) - cur，不是 max - cur

今日掌握的模板：

  • 快慢指针万能写法：slow 标记写入点，fast 扫描，条件满足就 swap
  • 左右指针相向而行：每次决策基于「排除不可能的方向」——#11 动矮不划算，#42 矮侧水位已确定
