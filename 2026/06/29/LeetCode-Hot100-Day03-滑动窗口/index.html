LeetCode Hot 100 Day 03 — 滑动窗口（#3 / #438）

滑动窗口是双指针的子串专精版——两个指针 left / right 都从左往右走，维护中间一段连续区间，像一扇窗户在字符串上滑过去。核心操作就两个：right 扩张、left 收缩。

本日题目：

# 题目 难度 窗口类型 核心思想
3 无重复字符的最长子串 Medium 变长窗口 right 扩，遇重复→left 跳到重复之后
438 找到所有字母异位词 Medium 固定长窗口 窗口长度 = p.len，每次滑一格，改两个计数

两种变体：

一、#3 无重复字符的最长子串 — 变长窗口

题目速览

给字符串 s，找不含重复字符的最长子串长度。

"abcabcbb" → 3（"abc"）

思路

窗口 [left, right] 就是当前的无重复子串。right 每走一步：

  • 如果 s[right] 没在窗口出现过 → 窗口合法，更新答案
  • 如果出现过 → left 直接跳到重复字符后一个位置，恢复合法

用 HashMap 记录每个字符最近一次出现的位置，left 跳过即可，不用一格一格收。

复杂度

  • 时间 O(n)：每个字符进窗口一次、出窗口一次
  • 空间 O(k)：k = 字符集大小（最多 128，ASCII）

答案 3。

面试要点

  • seen.get(c) >= left 是关键：seen 存了所有历史位置，但只有 ≥ left 的才算”窗口里”的重复
  • 为什么 left 直接跳，不慢慢收：因为 seen 记住了精确位置，O(1) 就到位
  • 变种：和 #159 至多两个不同字符的最长子串不同——#3 要求零重复，所以是”遇重复→跳”

🔑 一句话模板：right 扩→查 seen→如果重复在当前窗口内→left 跳到重复后一位→更新 seen→更新答案。

二、#438 找到所有字母异位词 — 固定长窗口

题目速览

给 s 和 p，找 s 中所有是 p 的字母异位词的子串起始下标。

s = "cbaebabacd", p = "abc" → [0, 6]（"cba"、"bac" 都是 abc 的异位词）

什么是字母异位词：字母组成完全一样的两个字符串。"abc" 的异位词 = abc, acb, bac, bca, cab, cba——各一个 a、b、c，只是顺序不同。

思路：固定窗口 + HashMap 计数比较

窗口长度固定 = p.length()。每次滑一格：移出一个字符、移入一个字符，只改两个计数，然后和 pMap 比较。

复杂度

  • 时间 O(n)：滑动 n 次，HashMap.equals 开销 O(k)，k 为 p 中不同字符数
  • 空间 O(k)

面试要点

  • 为什么 HashMap 归零要 remove：equals 比较两个 map 的 key 集合——{"a":0} ≠ {}，归零不删会导致比较结果错误
  • 固定 vs 变长：固定窗口 left 每轮必移，代码里用 for (int i = 0; i < sLen - pLen; i++) 表达，比 while 更清晰
  • HashMap vs int[26]：HashMap 直观但稍慢；int[26] 用 char - 'a' 做下标更快但可读性差。面试时先讲 HashMap 思路，再说可以优化到 int 数组
  • 变种：#567 字符串排列（完全一样的解法，返回 boolean）

四、本日回顾

题 窗口类型 核心技巧 易错点
#3 变长 seen 记字符位置，left 直接跳 seen[c] >= left 才算窗口内重复

今日掌握的模板：

  • 变长窗口：for right: 加入 → while 不合法 left++ → 更新
  • 固定窗口：for i: 移出 s[i]; 移入 s[i+pLen]; 比 equals
