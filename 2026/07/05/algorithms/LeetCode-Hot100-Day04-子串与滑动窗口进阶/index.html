一、#560 和为 K 的子数组 — 前缀和 + HashMap

题目速览

给整数数组 nums 和整数 k，统计和为 k 的连续子数组的个数。

nums = [1,2,3], k = 3 → 2（[1,2] 和 [3]）

为什么滑动窗口不行

数组有负数——right 扩张和不一定会增大，left 收缩和不一定会减小。窗口失去方向性。

思路：前缀和 → 两数之和

前缀和 = 从头累加到当前位置的和。子数组 nums[i..j] 的和 = preSum[j] - preSum[i-1]。

问题转化：preSum[j] - preSum[i-1] == k → preSum[i-1] == preSum[j] - k。

这就回到 Day 01 的两数之和：遍历 j，查前面有几个前缀和等于 sum - k。

  • 时间 O(n)
  • 空间 O(n)

二、#76 最小覆盖子串 — 变长窗口 + valid

题目速览

在 s 中找包含 t 所有字符的最短子串。

s = "ADOBECODEBANC", t = "ABC" → "BANC"

思路

窗口 [left, right] 要包含 t 所有字符。两步循环：

  1. right 一直扩，直到窗口够用（包含 t 的所有字符）
  2. 够了之后 left 往右收，挤掉多余字符，找最短

判断”够用”：两个 HashMap + valid 计数器。

复杂度

  • 时间 O(n)：每个字符进一次、出一次
  • 空间 O(k)

三、#239 滑动窗口最大值 — 单调队列

题目速览

给数组 nums 和窗口大小 k。窗口每次右滑一格，返回每个窗口里的最大值。

nums = [1,3,-1,-3,5,3,6,7], k = 3 → [3,3,5,5,6,7]

思路推演（从暴力到最优）

暴力：每个窗口扫一遍 k 个元素 → O(n×k)，超时。

TreeSet（有序集合）：窗口元素全装进 TreeSet，滑出就 remove，取答案就 last() → O(n log k)。可用但不最优。

大顶堆：PriorityQueue 自动排好，堆顶过期的 poll 掉 → O(n log k)。

单调递减队列（最优）：一个递减 deque 既当队列又当候选池。队头永远是最大；队尾管理”新人入队 + 踢掉小的”；队头下标过期就弹掉。O(n)。

核心规则：新人从队尾入队时，把所有比自己小的全踢飞——理由：它们又小又靠前，这辈子不可能当 max。

复杂度

  • 时间 O(n)：每个元素入一次、出一次
  • 空间 O(k)：队列最多存 k 个下标

代码（left/right 双指针 + 递减 deque）

走例 [1,3,-1,-3,5,3,6,7], k=3

right nums 入队动作 dq(下标→值) 答
0 1 空，直接入 [0→1] —
1 3 3>1 踢 0 [1→3] —
2 -1 -1<3 直接入 [1→3, 2→-1] 3
3 -3 -3<-1 直接入 [1→3, 2→-1, 3→-3] 3
4 5 5>-3 踢 3, 5>-1 踢 2, 5>3 踢 1 [4→5] 5
5 3 3<5 直接入 [4→5, 5→3] 5
6 6 6>3 踢 5, 6>5 踢 4 [6→6] 6
7 7 7>6 踢 6 [7→7] 7

[3,3,5,5,6,7] ✅

Deque 三组方法对照

操作 方法 在哪里用
看队头 peekFirst() 取答案、判断是否过期
弹队头 pollFirst() 过期时删掉
看队尾 peekLast() 新人入队前比较值大小
弹队尾 pollLast() 踢掉比自己小的
入队尾 offerLast(i) 新人从尾巴进去

单调队列 vs 大顶堆 vs TreeSet

单调队列 大顶堆 TreeSet
取最大 O(1) O(1) O(log k)
删过期 O(1) O(log k) O(log k)
入队 摊还 O(1) O(log k) O(log k)
总复杂度 O(n) O(n log k) O(n log k)
空间 O(k) O(k) O(k)

四、本日回顾

题 套路 核心 易错点
#560 前缀和 + HashMap sum - k 在不在 map map.put(0,1) 不能漏
#76 变长窗口 + valid right 扩到够，left 收到短 HashMap 值用 equals 比较

今日掌握的模板：

  • 前缀和找子数组和 = k：if sum - k in map
  • 最小覆盖子串：need + window + valid，够 → 收 → 记 → 不够 → 扩
  • 单调递减队列：while 队尾值 < 新人 踢飞；offerLast；if 队头过期 pollFirst
