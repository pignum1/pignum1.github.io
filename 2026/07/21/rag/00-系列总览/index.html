各阶段概览

阶段一：01 基础篇 — 从零搭建 RAG

🎯 理解 RAG 三大组件，能从头搭建最简 RAG 系统。

关键知识点：40 行代码速览 / 5 种 Chunking 策略 / 上下文分块（Recall 41%→78%）/ BM25 + 混合检索 + RRF / Bi-Encoder vs Cross-Encoder / 三阶段检索流水线 / 性能基准（Recall 72%→88%）/ 多模态统一成文本 / RAG vs Fine-tuning

阶段二：02 查询变换篇 — 把问题变好，检索才能变准

🎯 5 种技术解决同一个问题：用户问得不好 → 检索找不到 → 答案不对。

关键知识点：Multi Query 多角度查询 / RAG-Fusion + RRF 排序 / Decomposition 问题分解（串行/并行） / Step Back 退一步问 / HyDE 用假答案向量检索

阶段三：03 路由与查询构造篇 — 不同问题走不同库

🎯 多知识库场景下，问题该查哪个库？怎么加过滤条件缩小范围？

关键知识点：逻辑路由（LLM Function Calling）/ 语义路由（向量相似度）/ Query Structuring（元数据提取 + filter）

阶段四：04 高级索引篇 — 用更聪明的方式组织索引

🎯 Flat chunking 不够用时，如何提升索引质量？

关键知识点：Multi-representation（摘要检索 + 原文返回）/ RAPTOR（递归聚类树状索引）/ ColBERT（Token 级向量 MaxSim 匹配）

阶段五：05 高级检索与生成篇 — 让检索和生成形成闭环

🎯 检索完了还敢不敢信？信错了怎么办？生成内容有没有依据？

关键知识点：Re-ranking（粗排→精排）/ CRAG（检索质量评估 + 自动补救）/ Self-RAG（生成中持续自省）/ Long Context vs RAG（互补而非替代）
