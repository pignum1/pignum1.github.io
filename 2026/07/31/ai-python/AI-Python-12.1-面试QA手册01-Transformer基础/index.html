Q1：Self-Attention 的计算过程？复杂度？

展开答案

核心原理

Self-Attention 分四步。一，每个 token 通过三个权重矩阵生成 Q、K、V——Q 负责查询、K 负责被匹配、V 携带实际信息。二，Q 和所有 K 做点积，算出每对 token 的关联分数，得到一个 n×n 的注意力矩阵。三，除以 √d_k 防止点积太大导致 softmax 梯度消失，再用 softmax 把分数变成概率权重。四，用这些权重对所有人的 V 做加权求和——每个 token 的输出就是整个序列信息的加权混合。

复杂度 O(n²d)，瓶颈在 n×n 的注意力矩阵，长序列靠 Flash Attention 分块计算解决。

面试话术（30秒）

“SATT 四步：QKV 投影 → Q×K^T 算分数 → ÷√d_k + softmax → ×V 加权求和。O(n²d)，瓶颈在中间 n×n 矩阵，Flash Attention 用分块在 SRAM 算解决。”

易混淆点

  • ❌ “除以 √d_k 是为了归一化到 [0,1]” → ✅ softmax 才是归一化，÷√d_k 是为了防止点积太大导致梯度消失
  • ❌ “输出是一个分数” → ✅ 输出是 V 的加权和，是一个新向量，维度和输入一样

Q2：Self-Attention 的输出是什么？

展开答案

核心原理

输出是每个 token 的上下文增强向量。和输入形状完全一样——n 个 token，每个 512 维。但内容变了——原来是孤立的只包含自己的信息，经过 Self-Attention 后融入了整个序列所有 token 的信息。比如 “it” 的向量里混入了 “cat” 的语义，模型就理解了代词的指代关系。

面试话术

“输出是同样形状的上下文增强向量——每个 token 不再是孤立的，而是融合了整个序列的信息。”

易混淆点

  • ❌ “最终得到分数/权重” → ✅ 权重只是中间产物，最终输出是 V 的加权和

Q3：MHA / MQA / GQA 有什么区别？

展开答案

核心原理

MHA 每个头有独立的 K、V，KV Cache 最大。MQA 所有头共享一份 K、V，KV Cache 最小但精度掉分。GQA 折中——把头分成几组，组内共享 K、V。LLaMA 用 GQA，KV Cache 省了一半，精度基本不掉，是现在的主流方案。

面试话术

“MHA 每头独立 KV → Cache 大但精度好。MQA 全头共享 → 省 8× Cache 但掉精度。GQA 分组共享 → 省一半，不掉精度，LLaMA 全系在用。”

易混淆点

  • ❌ “共享 KV 是指所有 token 共用一份 KV” → ✅ 是同一个 token 内部的 8 个头共享，不是跨 token 共享

Q4：RoPE 的原理？和 Sinusoidal 的区别？

展开答案

核心原理

Sinusoidal 是绝对位置编码——直接给向量加固定位置值，外推长度差。RoPE 把位置信息编码成旋转角，乘在 Q 和 K 上——核心效果是 Q×K^T 点积结果自动包含两个 token 的相对位置差，天然编码了”距离几个 token”这种对语言最关键的相对关系。而且旋转角可以连续外推，训练 2048 推理 128K 没问题。LLaMA 全系都在用。

面试话术

“Sinusoidal 绝对位置、不可外推。RoPE 旋转编码——QK 点积结果自带相对位置差，且可连续外推训练时未见过的长度。LLaMA 全系标配。”

易混淆点

  • ❌ “RoPE 是给 embedding 加东西” → ✅ 是乘旋转矩阵，不是加；效果是相对位置编码

Q5：LayerNorm vs RMSNorm？为什么不用 BatchNorm？

展开答案

核心原理

BatchNorm 依赖 batch 维度统计，不适合变长序列，推理时 batch=1 会出问题，所以 NLP 都用 LayerNorm——对每个 token 自己做归一化。RMSNorm 是 LayerNorm 的简化版，省掉减均值的操作，精度基本不变但快 10-15%，LLaMA 全系在用。

面试话术

“BatchNorm 跨样本，不适合变长+推理 batch=1。LayerNorm 逐 token 归一化，NLP 标配。RMSNorm 省了减均值，更快，LLaMA 全系用。”

易混淆点

  • ❌ “BatchNorm 和 LayerNorm 归一化同一个维度” → ✅ BN 跨 batch 维度，LN 跨特征维度

Q6：BERT 和 GPT 的区别？为什么选 Decoder-Only？

展开答案

核心原理

BERT 双向注意力 + 完形填空式训练，适合理解任务但每个任务要单独加输出头。GPT 因果注意力 + Next Token Prediction，训练效率高——一句话复用 N 个样本，而且所有任务统一成续写。Scaling Laws 也验证了 Decoder-Only 随规模持续增强，所以现代 LLM 全是这个架构。

面试话术

“BERT 双向+MLM，理解强但每任务加头。GPT 因果+NTP，一句话 N 个样本，所有任务统一续写。训练效率+Scaling Laws 验证→Decoder-Only 一统天下。”

易混淆点

  • ❌ “BERT 只能做分类，GPT 只能做生成” → ✅ GPT 也可以做分类（Prompt 设计），且所有 Decoder-Only 模型都能同时做理解和生成

Q7：KV Cache 原理？怎么省计算量？

展开答案

核心原理

生成每个 token 时，之前 token 的 K、V 不用重新算——缓存起来直接复用。每次只算新 token 的 K、V 并追加到缓存。无缓存生成复杂度 O(n³d)，有缓存降到 O(n²d)，实际快 10 倍。代价是显存——2048 token 约 1GB，所以 MQA/GQA 省 KV Cache 才那么重要。

面试话术

“历史 token 的 K、V 缓存复用，每次只算新 token。O(n³)→O(n²)，实际快 10 倍。代价显存——2048 token ≈ 1GB，GQA 就是为省这个。”

易混淆点

  • ❌ “缓存的是 Attention 的输出” → ✅ 缓存的是 K 和 V 的原始矩阵，不是 softmax 后的结果
